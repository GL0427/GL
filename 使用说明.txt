iQing 校园网自动登录 v1.0
==========================

适用范围
--------
Wi-Fi 名称：iQing
认证门户：http://10.1.7.3/eportal/
系统：Windows 10 / Windows 11

安装
----
1. 双击“iQing校园网自动登录.exe”。
2. Windows 会弹出管理员授权窗口，选择“是”。
3. 输入自己的校园网账号和密码。
4. 点击“保存并安装”。

每台电脑、每个账号都要单独执行一次以上步骤。安装包本身不包含任何人的账号或密码。

工作方式
--------
软件会安装一个开机自动启动的 Windows 服务，并创建全用户 iQing Wi-Fi 配置。
服务依赖 Windows WLAN 服务，可在用户尚未登录 Windows 时连接 iQing 并尝试认证。
如果正在使用其他 Wi-Fi，程序不会强制切换；只有未连接 Wi-Fi 时才会尝试连接 iQing。

安全
----
账号密码通过 Windows DPAPI 机器级加密保存于：
C:\ProgramData\CampusAutoLogin\credential.bin

该目录仅 SYSTEM 和本机管理员可访问。日志不会记录明文账号或密码。

修改账号密码
------------
重新打开软件，输入新账号和密码，再点击“保存并安装”。

卸载
----
打开软件并点击“卸载”。卸载会删除后台服务和保存的凭据，但保留 iQing Wi-Fi 配置。

注意事项
--------
1. 开机前无线网卡必须开启，且 iQing 必须在信号范围内。
2. 首次安装需要管理员权限，这是安装开机服务所必需的。
3. 软件未购买商业代码签名证书，其他电脑可能显示“未知发布者”或 SmartScreen 提示。
4. 本版本只适配上面列出的 iQing 门户，不适用于其他学校不同的认证系统。
